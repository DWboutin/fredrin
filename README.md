# fredrin

An "about me" page that doubles as Mike Boutin's resume, built as the application for the
[Senior Software Engineer role at Fredrin](https://www.fredrin.com/careers/senior-software-engineer).

## Status

The repository holds only this README so far. There is no app code yet, so there is nothing to
install or run.

## Planned stack

- [Next.js](https://nextjs.org) with the App Router
- TypeScript
- Static rendering: pages are generated at build time

## Install

```sh
git clone https://github.com/DWboutin/fredrin.git
cd fredrin
```

There are no dependencies to install until the Next.js app is added.
